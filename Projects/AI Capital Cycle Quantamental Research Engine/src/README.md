# Source directory

This directory contains learner-authored numbered scripts.

- The learner writes every assignment-code line.
- [Mentor Mode](../../../MENTOR_MODE.md) controls explanations, code review, and the solution boundary.
- [PROGRESS.md](../../../PROGRESS.md) records task, phase, and overall completion from observed evidence.
- Keep the active file small enough to explain completely.
- Use functions that accept inputs and return results.
- Do not overwrite earlier demonstrated work; add the next numbered file when the task changes.
- Record substantial assistance in the task evidence.
- Do not add API keys, tokens, or provider credentials.

`01_vectorized_prediction.py` holds the assisted T01 prediction implementation. `02_cost_and_residuals.py` is the empty learner-owned file for T02; the mentor supplies teaching examples and fixture values, and the learner types its implementation.
