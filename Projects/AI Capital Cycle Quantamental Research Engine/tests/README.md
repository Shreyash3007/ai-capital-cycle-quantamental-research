# Tests directory

Tests verify behavior without replacing the learner's reasoning.

The tutor may provide black-box acceptance tests after the learner's cold attempt. The learner should also learn to write small assertions for shapes, numeric equality, changed inputs, and failure cases.

Tests are evidence only when the learner can explain what each assertion checks and why it matters.

ML-G01-T01 must at least verify that loop and vectorized predictions agree within an explicit floating-point tolerance.
