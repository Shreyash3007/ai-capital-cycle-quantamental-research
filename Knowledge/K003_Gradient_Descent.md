# K003: Gradient descent

**Course coverage:** C1W1, learner-reported. **Project evidence:** none yet.

Gradient descent changes parameters in the direction that lowers a differentiable cost locally. The learning rate controls update size. Too large a step can diverge; a decreasing training cost alone does not prove that the model generalizes.

**Requires:** [cost function](K002_Cost_Function.md), derivatives, and [multiple features](K004_Multiple_Features.md). **Used by:** [P00 T03](../PHASE_00_C1W2_PLAN.md). **Related:** [feature scaling](K006_Feature_Scaling.md).
