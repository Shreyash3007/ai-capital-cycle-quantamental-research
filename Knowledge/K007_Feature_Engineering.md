# K007: Feature engineering

**Course coverage:** C1W2, learner-reported. **Project evidence:** none yet.

Feature engineering creates a new input that represents a proposed relationship. A polynomial or interaction term can let a linear model express a nonlinear pattern, but extra flexibility can fit noise. In finance, the transformation needs an economic reason as well as a measured improvement.

**Requires:** [multiple features](K004_Multiple_Features.md), [cost and evaluation](K002_Cost_Function.md), and a finance hypothesis. **Used by:** [P00 T05](../PHASE_00_C1W2_PLAN.md). **Research standard:** [signal program](../SIGNAL_RESEARCH_PROGRAM.md).

**Demonstration gate:** state the mechanism before fitting, implement the feature, compare against the baseline, and explain one failure or overfitting risk. Link the eventual evidence here.
