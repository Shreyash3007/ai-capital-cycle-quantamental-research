# Knowledge index

## Status meaning

- **Course covered:** learner says the course taught this concept.
- **Introduced early:** mentor taught a concept before the learner completed its course week.
- **Project demonstrated:** learner implemented and explained it on original and changed cases.
- **Transferred:** learner independently used it in a different setting.
- **Planned:** no lesson or project evidence yet.

Course coverage and project demonstration are independent. The exact current task and percentages live in [PROGRESS.md](../PROGRESS.md).
