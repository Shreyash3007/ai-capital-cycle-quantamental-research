# K002: Cost function

**Course coverage:** C1W1, learner-reported. **Project evidence:** none yet.

A cost function turns prediction errors across observations into one quantity for optimization. In P00, squared error penalizes larger errors more strongly. A low training cost shows fit to those rows; it does not establish out-of-sample accuracy or financial value.

**Requires:** [linear regression](K001_Linear_Regression.md). **Used by:** [P00 T02 and later tasks](../PHASE_00_C1W2_PLAN.md). **Finance link:** [valuation residuals](K008_Valuation_Stretch.md).

**Demonstration gate:** calculate a tiny example by hand, implement it, test a changed target, and explain why a low cost may still be misleading. Link the eventual evidence here.
