# K001: Linear regression

**Course coverage:** C1W1, learner-reported. **Project evidence:** none yet.

Linear regression estimates a numeric target as a weighted sum of features plus a bias. The weights describe the model's fitted association under its chosen data and loss; they are not automatically causal or stable across market regimes.

**Requires:** [multiple features](K004_Multiple_Features.md) for the current model. **Used by:** [T01](../Goals/ML-G01%20-%20C1W2%20Valuation%20Stretch%20Foundation/T01%20-%20Vectorized%20Prediction.md), then the [P00 sequence](../PHASE_00_C1W2_PLAN.md). **Research meaning:** [valuation stretch](K008_Valuation_Stretch.md).
