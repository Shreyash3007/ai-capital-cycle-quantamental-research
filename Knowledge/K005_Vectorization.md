# K005: Vectorization

**Course coverage:** C1W2, learner-reported. **Project evidence:** none yet.

Vectorization expresses repeated row calculations as array operations. It can make the same operation clearer and faster when the shapes align. A vectorized expression is correct only if it matches the intended row-by-row calculation.

**Requires:** [multiple features](K004_Multiple_Features.md) and NumPy shape reasoning. **Used by:** [T01](../Goals/ML-G01%20-%20C1W2%20Valuation%20Stretch%20Foundation/T01%20-%20Vectorized%20Prediction.md) and [gradient descent](K003_Gradient_Descent.md).

**Demonstration gate:** write loop and vectorized forms, compare on original and changed inputs, and explain an incompatible-shape failure. Link the eventual evidence here.
