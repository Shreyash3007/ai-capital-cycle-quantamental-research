# K004: Multiple features

**Course coverage:** C1W2, learner-reported. **Project evidence:** none yet.

Each observation becomes a row of features. If there are `m` observations and `n` features, the matrix has shape `(m, n)` and each feature has one weight. A feature must have a defined unit, timestamp, and financial meaning before it enters a serious model.

**Requires:** [linear regression](K001_Linear_Regression.md). **Used by:** [T01](../Goals/ML-G01%20-%20C1W2%20Valuation%20Stretch%20Foundation/T01%20-%20Vectorized%20Prediction.md). **Data contract:** [DATA_DICTIONARY.md](../DATA_DICTIONARY.md).

**Demonstration gate:** identify every shape and unit; calculate one row's prediction; explain why more columns do not automatically create more useful evidence. Link the eventual evidence here.
